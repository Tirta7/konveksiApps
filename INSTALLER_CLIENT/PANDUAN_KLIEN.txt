========================================================================
PANDUAN LENGKAP INSTALASI & PENGGUNAAN SISTEM KONVEKSI (CLIENT / PABRIK)
========================================================================

1. PERSYARATAN:
   - Komputer Windows 10 atau Windows 11 (64-bit).
   - Koneksi internet aktif saat instalasi pertama kali & saat update.
   - Tidak perlu install Docker manual! Sistem akan mendeteksi dan
     mengunduh serta menginstall Docker Desktop secara otomatis.

2. CARA INSTALASI PERTAMA KALI:
   - Klik 2x file: "INSTALL.bat" (atau "START_CABANG.bat")
   - Script akan otomatis:
     a. Memeriksa apakah Docker Desktop sudah ada. Jika BELUM, script
        otomatis mengunduh dan menginstall Docker Desktop ke PC Anda!
        (Jika baru pertama kali diinstall, restart PC Anda 1x lalu klik
         kembali file INSTALL.bat).
     b. Membuka dan memastikan Docker Engine aktif di latar belakang.
     c. Mendeteksi Serial Number / Machine ID unik hardware PC ini.
     d. Mengunduh aplikasi Konveksi versi terbaru langsung dari cloud registry.
     e. Membuat shortcut di Desktop: "Aplikasi Konveksi" & "UPDATE".
     f. Membuka aplikasi secara otomatis di browser Chrome / Edge.

3. AKTIVASI LISENSI (JIKA MUNCUL LAYAR MERAH / KUNCI LISENSI):
   - Machine ID PC klien otomatis terkirim dan tercatat di server lisensi pusat.
   - Informasikan nama usaha / cabang Anda ke Admin / Pemilik Sistem.
   - Begitu lisensi disetujui, layar merah akan otomatis terbuka dalam 5 detik
     tanpa perlu restart atau setting ulang.

4. CARA UPDATE APLIKASI KE VERSI TERBARU:
   - Jika Developer / Anda memperbarui fitur aplikasi di GitHub:
     a. Pastikan file ".token" ada jika repository/image bersifat Private.
        (Salin dari ".token.example", rename menjadi ".token", lalu isi
         GitHub Personal Access Token Classic dengan centang 'read:packages').
     b. Cukup klik 2x file: "UPDATE.bat" (atau "UPDATE_CABANG.bat").
     c. Script otomatis mengunduh pembaruan dari cloud, merestart container,
        dan membuka aplikasi yang sudah terupdate!
     d. Data barang, transaksi, barcode, dan retur Anda 100% AMAN (tidak hilang).

5. CARA PENGGUNAAN SEHARI-HARI:
   - Cukup klik shortcut di Desktop: "Aplikasi Konveksi"
   - Atau klik file "BUKA_APLIKASI.bat"
   - Browser PC ini   : http://localhost:3001
   - Domain Online    : https://[subdomain].vocpos.id (jika cloudflare aktif)
   - Akses HP/Tablet  : http://[IP-KOMPUTER-SERVER]:3001 (dalam satu jaringan Wi-Fi)

6. CARA MEMATIKAN APLIKASI:
   - Klik 2x pada file: "STOP.bat" (atau "STOP_CABANG.bat")
